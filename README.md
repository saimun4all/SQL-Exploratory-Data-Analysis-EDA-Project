**Project Overview**: 

This project implements an Exploratory Data Analysis (EDA) framework using SQL to profiles data, ask targeted business questions, and uncover deep data insights.
Industry Covered: Retail & E-commerce (specifically focused on bicycle, clothing, and accessory sales across global markets).
Key Metrics Analyzed: Measures core business performance tracking total sales revenue (~$29M), total items sold (~60K), product profitability rankings, etc.
